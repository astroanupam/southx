# Deliverable 4 — API Specification (v1, draft)

Base: `/v1` · JSON · `Authorization: Bearer <JWT>` · `Accept-Language: en|hi|gu` (affects labels only, never numbers) · errors: `{code, message_key, details}` (clients translate `message_key`).

## Auth & account
| Method | Path | Purpose |
|---|---|---|
| POST | /auth/signup, /auth/login, /auth/logout, /auth/reset | via Supabase; thin proxy optional |
| GET/PATCH | /me | profile, locale, theme |
| POST | /me/export | async data export (JSON/CSV) |
| DELETE | /me | account + data deletion |

## Places & time
| GET | /places/search?q= | geocoder results {label, country, admin1, city, lat, lon} |
| POST | /time/resolve | in: local date/time, lat, lon (or tz_id). out: `tz_id, utc_offset_sec, dst_active, local_civil, utc_instant, source:"auto", tzdb_version, warnings[]` |
| POST | /time/resolve (with `manual_offset_sec`, `manual_reason`) | out `source:"manual"` |

## Settings
| GET/POST | /settings/calculation | list/create named setting sets |
| GET | /ayanamsha | catalogue incl. `engine_support` flags, reference epoch, standard vs custom |

## Charts (Stage 2+; return 501 `ENGINE_NOT_ENABLED` in Stage 1)
| POST | /profiles/{id}/charts | create immutable snapshot. body `{settings_id, rule_set:{...}}` |
| GET | /charts/{snapshotId} | full snapshot (positions, D-1, D-9, dignity, special results) |
| GET | /charts/{id}/divisional/{n} | D-1, D-9 (others future) |
| GET | /charts/{id}/planets/{body} | planet detail popover data |
| POST | /charts/{id}/recalculate | creates NEW snapshot; old retained |
| GET | /charts/{id}/provenance | engine, versions, hashes, rule versions |

## Rule registry & validation
| GET | /rules, /rules/{code}/versions | read for all authenticated |
| POST | /rules/{code}/versions/{v}/approve | role `reviewer`/owner only; writes `user_approvals` + audit |
| GET | /validation/cases, /validation/runs | |
| POST | /validation/runs | run harness |

## Conventions
- Longitudes are decimal degrees in `[0,360)`, serialized as strings with 9 decimals to avoid float drift; plus `dms` object for display.
- Every result object includes `rule: {code, version, status}`.
- Pagination: `?cursor=&limit=`. Idempotency: `Idempotency-Key` on POSTs creating snapshots.
- OpenAPI 3.1 generated by FastAPI; TypeScript client generated into `packages/api-client`.
